contract:     → production

installation: → completed, complaint

3. TYPY DOKUMENTÓW (convex/schema.ts)
----------------------------------------------------------------------

DOCUMENT_TYPES = ["pomiar", "umowa", "gwarancja_alco", "rekojmia_adk",
                  "odbior_inwestor", "protokol_montaz", "faktura", "reklamacja"]

Struktura documentEntry:
  enabled: boolean
  url?: string
  generatedAt?: number
  error?: string
  errorAt?: number
  signatureStatus?: "signed" | "not_applicable"

Logika kolorów kwadracików dokumentów (z designu):
  Szary  — dokument nie wygenerowany (enabled=false lub brak url)
  Czerwony — wygenerowany ale nie podpisany (jest url, brak signatureStatus="signed")
  Zielony  — wygenerowany i podpisany (signatureStatus="signed" lub "not_applicable")
